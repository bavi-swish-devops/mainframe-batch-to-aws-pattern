# Runbook

This document explains how to run the project locally in its current state.

## Overview

This repository contains two paths:

- **Legacy path**: COBOL batch program executed locally with GnuCOBOL
- **Modern path**: Rust application executed locally or through Docker

Both currently use the same logical fixed-width input dataset.

File:

legacy/data/input_fixed.dat
